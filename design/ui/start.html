How Strata reads a disk
Live volume

The file system as it was when the image was taken: files, the change journal, event logs, the registry.

Shadow copy 2

Windows keeps older versions of changed blocks. Each shadow copy is the whole volume at an earlier moment.

Shadow copy 1

Comparing copies shows what was changed, renamed or removed, and between which two moments.

Unallocated

Free space still holds records that were deleted. Strata carves file records, journal entries and event log chunks out of it.
